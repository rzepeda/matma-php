# MATMA's four verification tiers

## Unit: tests/unit/mirror/.../ClassTest.php
Generated as an intentionally failing PHPUnit-compatible test. Read real source behavior, validate success/error/edge outcomes and replace self::fail with observable assertions. Isolate genuine dependencies with centralized PHPUnit mock factories in tests/mocks/mirror; do not fabricate business data or use assertTrue(true).

## Interaction: tests/interaction/mirror/.../ClassInteractionTest.php
Generated as an intentionally failing starting file. Write real tests of component boundaries, Laravel providers, requests, database operations, queues, repositories or Artisan, using the host application's isolated test environment and real fixtures.

## Business: tests/business/*Test.php
NOT auto-generated by MATMA. Agent/developer must identify a confirmed business rule, build representative input/fixture and assert the observed workflow result. Register it explicitly only when a meaningful test file exists. Do not guess the business requirement.

## Regression: tests/regression/*Test.php
NOT auto-generated by MATMA. Author a deterministic reproduction of a known prior defect, external integration contract or E2E invariant with verified expectations; never put a fake passing assertion in place.

## Explicit workflow registry

See verification-registry.example.yaml; the developer owns tests/matma-verification.yaml. Each entry has a unique id, sources (real app-relative PHP paths or PSR-4 FQCNs), and tests (matching tests/business or tests/regression paths). Registered workflow matches are suggested in matma:impact results, not automatically executed or mixed into unit/interaction test lists.

## Agent completion report

Distinguish generated unimplemented stubs, authored test assertions, actually executed test commands and results, missing paths, registered business/regression cases and blockers. Run php artisan test when access permits. A generated self::fail stub failing is expected until authored. Do not change production code solely to make an invented test pass; report missing specifications instead.
