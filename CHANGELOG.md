# Changelog

All notable changes to MATMA PHP are listed here. The package has not yet published a tagged release.

## Unreleased — proposed v0.1.0

- **Phase 1:** Composer package integration, Laravel service provider and Artisan commands.
- **Phase 2:** PHP AST inspection, deterministic source/mirror path mapping and PSR-4 validation.
- **Phase 3:** Internal/external dependency graph, reverse shortest-path dependents, deterministic YAML manifests and freshness fingerprint inputs.
- **Phase 4:** Non-destructive generation of intentionally failing PHPUnit-compatible unit/interaction tests and centralized mock factories, with non-mockability diagnostics.
- **Phase 5:** Read-only impact selection from persisted YAML, missing/stale index checks, tier isolation and explicitly registered business/regression workflow suggestions.
- **Phase 6:** Complete Laravel consumer walkthrough, output snapshot tests, Linux/Windows CI (seven jobs), PHPStan/PHPCS quality checks, reproducible benchmark harness, Windows path-normalization fixes and release/adoption documentation.

Phase 6 CI evidence: [run 42336822288](https://github.com/rzepeda/matma-php/actions/runs/42336822288). No tag, GitHub Release or Packagist publication exists from this work. Pest-specific version certification remains a separate open compatibility item.
